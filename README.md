# Skill Lens AI

前后端分离项目，后端使用 Python FastAPI。

## 项目结构

```
├── backend/    # 后端服务 (FastAPI)
└── frontend/   # 前端应用
```

## 快速启动

### 后端

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

服务默认运行在 `http://localhost:8000`，API 文档访问 `http://localhost:8000/docs`。
